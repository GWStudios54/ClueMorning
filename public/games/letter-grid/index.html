What is Letter Grid?

Letter Grid is a free daily word guessing game. You have six attempts to identify the hidden word, using color feedback from each guess to narrow the possibilities. Unlike fixed-length word games, Letter Grid can serve answers from five to ten letters long.

Longer words change the rhythm of the puzzle. They give you more information per guess, but they also create more possible letter positions to reason through.

How to play Letter Grid

  1. Enter a valid word with exactly the number of letters shown for the day.
  2. Submit your guess to receive letter-by-letter feedback.
  3. Green letters are correct and in the correct position.
  4. Gold letters appear in the answer but belong somewhere else.
  5. Use the feedback to solve the word within six guesses.

Letter Grid strategy

Your first guess should usually test a useful spread of common letters rather than repeat the same character several times. Once you have green letters, preserve them unless you have a strong reason not to. Gold letters are especially valuable because they tell you both that a character belongs in the word and that its current position is wrong.

With longer words, look for familiar prefixes, suffixes, and letter patterns. A ten-letter answer can look intimidating at first, but several confirmed positions can collapse the search space quickly.

Scoring rewards efficient solves

Letter Grid rewards solving the word, and stronger performances come from using fewer guesses and less time. Longer daily words also carry a higher scoring multiplier, so difficult boards have more upside.

Letter Grid FAQ

How many guesses do I get?

You get six guesses for the daily word.

How long can the answer be?

The daily answer can be from five to ten letters long.

What does green mean?

A green letter is correct and already in the correct position.

What does gold mean?

A gold letter is part of the answer but belongs in a different position.
